# Raw Data

Place raw CSV files downloaded from the Telangana Open Data Portal here.

## Data Source
- **URL**: https://data.telangana.gov.in/dataset/daily-prices-market-yard-commodities-telangana
- **Format**: CSV
- **Contents**: Daily prices of market yard commodities in Telangana

## How to Download
Run `python download_data.py` to automatically download the latest data.
